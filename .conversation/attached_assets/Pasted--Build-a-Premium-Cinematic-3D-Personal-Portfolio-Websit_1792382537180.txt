# 10. Custom Orbital Cursor — Design and Implementation

Create a distinctive **Orbital Cursor** integrated with the website's visual identity.

## Cursor movement

- The central dot tracks the pointer responsively.
- The shell follows the pointer and remains centered around the central dot.
- The satellite revolves continuously around the shell's center at a controlled speed.
- The rings may rotate at different speeds or in opposite directions.
- Add subtle directional tilt based on pointer movement.
- Use smooth interpolation without noticeable lag or drift.

The cursor should feel like a small celestial object following the user.

## Cursor states

**Default:** A glowing central dot, orbital shell, and moving satellite.

**Hovering over links or buttons:**
- Expand the shell slightly.
- Increase the core's brightness.
- Subtly accelerate the satellite.
- Optionally reveal a short label such as "OPEN", "VIEW", or "EXPLORE".

**Hovering over projects:**
- Expand the cursor into a more visible orbital form.
- Display a short "VIEW PROJECT" label.

**Clicking:**
- Trigger a restrained ripple or ring expansion.
- Return smoothly to the default state.

**Scrolling:**
- Allow subtle orbital reactions without making the cursor distracting.

## CRITICAL BUG-PREVENTION REQUIREMENT: ORBITAL SHELL MUST NOT DRIFT

The orbital shell must remain centered around the central dot at all times. It must never continuously fly toward the top-left corner, slide away from the pointer, or accumulate positional offsets.

Keep the cursor's pointer position, the shell's rotation, and the satellite's orbit as separate transformations.

### Required implementation approach

1. Use a single parent cursor container to track the pointer.
2. Position the parent using a consistent viewport coordinate system, preferably `position: fixed` with `clientX` and `clientY`.
3. Apply pointer translation only to the parent container.
4. Center the central dot and shell relative to that parent, using an appropriate layout and/or `translate(-50%, -50%)`.
5. Give the shell its own nested element for rotation. Never overwrite the parent's pointer-following transform with the shell's rotation animation.
6. Give the satellite its own nested element or orbit container so its movement is calculated relative to the shell's center.
7. Set the shell's `transform-origin` to its own center.
8. Check that no CSS animation, GSAP tween, or JavaScript update writes conflicting transforms to the same element.
9. Do not mix viewport coordinates (`clientX`, `clientY`) with page coordinates (`pageX`, `pageY`) or apply unnecessary scroll offsets.
10. Use a consistent DOM positioning hierarchy. Avoid positioning the shell relative to an unrelated ancestor.
11. Ensure there is only one active pointer-tracking animation loop.
12. Clean up event listeners, animation frames, and animation instances when the component unmounts.
13. Keep `pointer-events: none` on the decorative cursor layers.
14. Do not use a hard-coded top-left offset, hide the shell, or remove the orbital animation as a workaround.

If the existing cursor uses CSS transforms, inspect whether the pointer-position transform and rotation transform are overwriting each other. If it uses GSAP, check whether GSAP and CSS animations are controlling the same transform property.

Adapt the fix to the actual implementation instead of blindly duplicating the cursor component.

### Cursor testing requirements

After implementation, verify all of the following:
- The shell remains centered around the central dot while the pointer moves.
- The satellite follows a stable circular path around the center.
- Moving the pointer in all four directions does not cause drift.
- Moving the pointer in circles does not cause the shell to detach.
- Scrolling does not displace the cursor.
- Hover and click effects continue to work.
- The cursor does not block clicks, links, buttons, or text selection.
- No duplicate animation loops or console errors are introduced.

**Do not consider the cursor complete until the shell remains correctly positioned while the pointer moves and the satellite continues revolving.**
